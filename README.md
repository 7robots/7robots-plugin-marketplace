# 7robots plugin marketplace

One plugin, `7robots`, connects Claude Code and Codex to the 7robots MCP fleet
through the Cloudflare MCP portal at `https://mcp.7robots.org/mcp`. Sign in once
(Cloudflare Access) and every server's tools appear, prefixed by server:
`moon_`, `solar_`, `dnd_`, `books_`, `news_`, `huit_`, `images_`. Each server's
skill ships in `plugins/7robots/skills/<server>/`.

## Install

**Claude Code**
```
/plugin marketplace add 7robots/7robots-plugin-marketplace
/plugin install 7robots@7robots-plugin-marketplace
```

**Codex**
```
codex plugin marketplace add 7robots/7robots-plugin-marketplace
```

## Layout

```
.claude-plugin/marketplace.json      # Claude catalog
.agents/plugins/marketplace.json     # Codex catalog
plugins/7robots/                     # the plugin: .mcp.json, skills/, manifests
```

Everything here is generated by MCP Studio (`studio plugin publish` in
`7robots/7robots-mcp`) from the servers' own skills. Do not edit by hand.
